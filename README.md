# 🧮 Calculadora em Python

Uma calculadora simples de linha de comando feita em Python, sem bibliotecas externas.

## Funcionalidades

- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão (com tratamento de divisão por zero)
- 🔺 Potência
- 🔁 Resto da divisão
- √ Raiz quadrada
- Aceita números decimais com ponto ou vírgula (ex.: `3.5` ou `3,5`)

## Requisitos

- Python 3.6 ou superior

## Como executar

```bash
git clone https://github.com/SEU-USUARIO/calculadora-python.git
cd calculadora-python
python calculadora.py
```

## Exemplo de uso

```
===== CALCULADORA =====
  +   Soma
  -   Subtração
  *   Multiplicação
  /   Divisão
  **  Potência
  %   Resto da divisão
  r   Raiz quadrada
  s   Sair
=======================
Escolha a operação: *
Digite o primeiro número: 7
Digite o segundo número: 6

Resultado: 7 * 6 = 42
```
